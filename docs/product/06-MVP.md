# 凌睿科技导航页 V3 MVP 定义

> 文档状态：v1.0 · 归属：凌睿科技导航页 · 关联：05-PRD.md（F-01~F-09）、02-用户故事.md（US-xx）

---

## 1. MVP 目标

用 2 周时间，在**不破坏现有功能**的前提下，交付四个用户可感知的核心能力：主页可组装（拖拽排序 + 组件开关）、数据可备份（导入导出）、视觉可切换（深/浅主题）。同时把存储层数据结构升级为可迁移版本（schemaVersion），为后续迭代打基础。

MVP 验证的核心假设：**"隐私纯净 + 本地可控"的定位下，用户愿意用本地导入导出替代云同步，并愿意自定义主页结构。**

## 2. MVP 包含范围

### 2.1 必须（P0，对应 PRD F-01~F-04）

| 功能 | 对应故事 | 验收要点 |
|------|----------|----------|
| 统一排序数据结构 | US-03 | 书签/分类/组件共用 sortOrder 语义，写入与读取一致 |
| 书签拖拽排序 | US-01 | 拖拽换位即时保存，刷新后保持，支持键盘上下移 |
| 分类拖拽排序 | US-02 | 分类卡片可拖拽换位，子链接随分类移动不丢失 |
| 组件注册机制 | US-05 | 搜索/书签/分类/待办/天气/农历/壁纸均可按注册表渲染 |
| 组件显示开关 | US-04 | 设置页可开关组件，关闭后主页区块隐藏且持久化 |
| 导出 JSON 备份 | US-07 | 一键导出完整配置（书签/分类/组件/设置/待办） |
| 导入 JSON 恢复 | US-08 | 导入校验通过后完整还原；校验失败给出明确错误，不破坏现有数据 |
| 深浅主题切换 | US-10 | 设置页切换深/浅主题，即时生效并持久化 |

### 2.2 基线要求（现有功能不得回归）

- 搜索（三引擎切换）、待办 CRUD、天气显示与 24h 预报、农历日历浮层、壁纸切换与取色、设置面板原有功能。
- 首次打开 3 秒内可用；无控制台报错。

## 3. MVP 明确不包含

### 3.1 本期不做（后续版本）

- 组件顺序拖拽调整（US-06，P1）——MVP 只做开关，顺序按预设。
- 主题与壁纸联动（US-11，P1）。
- 节假日倒计时、农历信息卡片增强、数据双源容错（US-12/13/14，P1）。
- 隐私可见化页面、网络请求审计（US-15/16，P1/P2）。
- 自动化测试体系完善（US-17，P1）——MVP 允许先做手动冒烟清单。
- 可复现打包（US-18，P2）。
- 跨浏览器兼容与网页预览模式（US-19/20，P2）。
- 天气优雅降级、搜索快捷键（US-21/22，P1/P2）。

### 3.2 战略排除（永不纳入，除非用户变更决策）

- Chrome Web Store 上架。
- AI 组件/智能推荐。
- 移动端、网页版。
- 云同步、账号体系。

## 4. MVP 成功标准（可量化）

| 指标 | 目标 | 测量方式 |
|------|------|----------|
| 导出还原率 | 导出 JSON 重新导入后，书签/分类/组件设置/待办完整还原，字段一致率 100% | 自动化对比脚本 |
| 排序持久化 | 拖拽后刷新页面，顺序保持率 100% | 手动/脚本验证 |
| 组件开关 | 开关状态刷新后保持率 100% | 手动验证 |
| 主题切换 | 深/浅主题切换即时生效，CSS 变量无遗漏 | 视觉检查 + 变量断言 |
| 功能回归 | 现有功能冒烟清单通过率 100% | 手动冒烟清单（20 项） |
| 页面性能 | 首屏可用时间 ≤ 3s，DOMContentLoaded 无新增阻塞 | Performance 面板 |
| 数据安全 | 导入非法文件不破坏现有数据，回滚成功 | 异常导入用例 |

## 5. MVP 验收方式

1. **功能验收**：按 02-用户故事.md 中 P0 故事（US-01~05、US-07、US-08、US-10）的验收标准逐条执行。
2. **回归验收**：执行现有功能冒烟清单（搜索/书签/分类/待办/天气/农历/壁纸/设置）。
3. **数据验收**：构造"导出 → 清空 → 导入"往返用例，比对 JSON 差异。
4. **边界验收**：空书签、50+ 书签、中文/特殊字符标题、导入损坏文件、导入旧版本文件。
5. **发布验收**：本地加载扩展无报错；zip 打包物与源码一致。

## 6. MVP 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 拖拽实现复杂导致延期 | 高 | 先用 HTML5 DnD 最小实现，键盘替代作为 P1 兜底 |
| 导入格式兼容历史数据 | 高 | schemaVersion + 迁移函数，旧数据自动升级 |
| 组件化改造破坏现有渲染 | 高 | 注册表逐步迁移，每步跑冒烟清单 |
| 主题变量遗漏导致观感差 | 中 | 深色主题逐组件视觉检查清单 |
