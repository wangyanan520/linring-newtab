# 凌睿科技导航页 产品线路（Product Roadmap）

> 文档状态：v1.0 · 归属：凌睿科技导航页 · 关联：05-PRD.md、06-MVP.md、07-产品待办.md（PBI-xx）
> 时间说明：相对时间，从 2026-08-17 起算；不含商店上架（战略排除项）

---

## 路线总览

| 阶段 | 名称 | 时间 | 主题 | 对应待办 |
|------|------|------|------|----------|
| Phase 1 | MVP | 第 1-2 周 | 可组装 + 可备份 + 可切换 | PBI-01~07、PBI-09 |
| Phase 2 | 体验增强 | 第 3-4 周 | 本土化 + 隐私 + 稳定性 | PBI-08、PBI-10~13、PBI-18 |
| Phase 3 | 工程化与多端 | 第 5-8 周 | 测试 + 打包 + 跨浏览器 | PBI-14~17 |

---

## Phase 1：MVP（第 1-2 周）

**目标**：交付用户可感知的三大能力——主页可组装（拖拽排序 + 组件开关）、数据可备份（导入导出）、视觉可切换（深浅主题）。

**范围**：
- 统一排序数据结构（PBI-01）
- 书签/分类拖拽排序（PBI-02/03）
- 组件注册机制与显示开关（PBI-04/05）
- 导出/导入 JSON 备份（PBI-06/07）
- 深浅主题切换（PBI-09）

**退出标准**：
- 06-MVP.md 中 MVP 成功标准全部达成（导出还原率 100%、排序/开关/主题持久化、冒烟通过、首屏 ≤3s）。
- 现有 7 大功能无回归。
- 无 P0 缺陷。

---

## Phase 2：体验增强（第 3-4 周）

**目标**：强化差异化（农历/节假日）、把隐私承诺变成可见功能、提升异常场景稳定性。

**范围**：
- 数据迁移兼容（PBI-08）
- 主题与壁纸联动（PBI-10）
- 节假日倒计时与农历信息增强（PBI-11）
- 节假日数据双源容错（PBI-12）
- 隐私可见化（PBI-13）
- 天气优雅降级与搜索快捷键（PBI-18）

**退出标准**：
- 全部 P1 待办完成并通过验收标准。
- 日历浮层在离线/双源故障下可降级使用。
- 设置面板具备"隐私与数据"区块。

---

## Phase 3：工程化与多端（第 5-8 周）

**目标**：让项目具备可持续迭代的工程基础（测试、可复现打包），并评估跨浏览器分发。

**范围**：
- 核心逻辑自动化测试（PBI-15）
- 网络请求审计（PBI-14）
- 可复现打包（PBI-16）
- Firefox/Edge 兼容与网页预览模式（PBI-17）

**退出标准**：
- `node --test` 核心纯函数覆盖率 ≥ 80%。
- 打包脚本一条命令产出与源码一致的干净 zip。
- Firefox/Edge 冒烟通过（若投入完成）；若评估成本过高，保留 Chrome 单端并记录决策。

---

## 战略排除（明确不做）

| 项 | 原因 |
|----|------|
| Chrome Web Store 上架 | 用户决策暂缓；分发物保持 zip |
| AI 组件/智能推荐 | 超出"隐私纯净、轻量"定位，且需要服务端能力 |
| 移动端/网页版 | 无运营与后端资源，新标签页主场景在桌面 |
| 云同步/账号体系 | 用户决策不做；以本地导入导出替代 |

---

## 风险与依赖说明

- 所有阶段都依赖"现有功能零回归"基线，冒烟清单随每个 Phase 回归。
- 组件化（PBI-04）是 Phase 1 与 Phase 3 的共同地基，优先完成。
- 测试体系（PBI-15）在 Phase 1 允许以手动冒烟代替，Phase 3 必须自动化。
