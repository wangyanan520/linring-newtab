# 凌睿科技导航页 — MVP（最小可行产品文档）

## 1. MVP 定义

MVP（Minimum Viable Product）是产品的第一个可用版本，包含核心功能闭环，能够验证产品价值。

### 1.1 MVP 目标
- 实现新标签页替换的核心能力
- 用户可以正常搜索、访问常用网站
- 页面美观可用，满足日常使用需求
- 整体开发周期控制在 3-5 天内

## 2. MVP 范围

### 2.1 ✅ 包含的功能（P0）

| 功能 | 说明 | 工作量预估 |
|------|------|-----------|
| 新标签页覆盖 | manifest.json 配置，安装即用 | 0.5h |
| 导航页布局 | 完整页面布局 + 响应式适配 | 2h |
| 搜索框 | 默认 Google 搜索，回车跳转 | 1h |
| 快捷书签 | 8个预设书签+自定义增删改 | 3h |
| 分类导航 | 4个预设分类+40个链接，展开折叠 | 3h |
| 时间显示 | 当前日期时间 | 0.5h |
| 壁纸切换 | 6张内置壁纸，随机+手动切换 | 2h |
| 本地存储 | chrome.storage 读写封装 | 1.5h |
| 设置面板 | 书签/分类的管理界面 | 3h |

### 2.2 ❌ 不包含的功能（推迟到 V1.1+）

| 功能 | 推迟原因 |
|------|---------|
| 天气显示 | 需要 API Key 注册，可单独加 |
| 深色模式 | 非核心功能，后续增强 |
| 搜索引擎切换 | MVP 先固定 Google，后续扩展 |
| 拖动排序 | 实现复杂度较高，后期优化 |
| 搜索引擎切换 | 同上 |

### 2.3 合计工作量
约 **16.5 小时**，按每天 4-5 小时估算，约 **3-4 天** 完成。

## 3. MVP 交付标准

### 3.1 功能验收清单
- [ ] 安装扩展后，打开新标签页显示凌睿科技导航页
- [ ] 搜索框输入关键词按回车可跳转 Google 搜索结果
- [ ] 搜索框有清除按钮
- [ ] 快捷书签显示 8 个预设网站，点击可跳转
- [ ] 快捷书签支持添加/编辑/删除
- [ ] 分类导航显示 4 个预设分类，点击可展开折叠
- [ ] 分类导航的链接点击可跳转
- [ ] 分类导航支持添加/编辑/删除分类和链接
- [ ] 页面顶部显示当前日期和时间
- [ ] 底部工具栏有壁纸切换按钮，点击可切换壁纸
- [ ] 设置面板可打开关闭，管理功能可用
- [ ] 所有用户修改的数据刷新后保留

### 3.2 质量验收清单
- [ ] 页面加载时间 < 1s
- [ ] 页面在不同分辨率下显示正常
- [ ] 无控制台报错
- [ ] 扩展包体积 < 5MB

## 5. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| chrome.storage 配额限制 | 存储数据过多超出 5MB | MVP 数据量小，远未达到限制 |
| 壁纸图片加载慢 | 首次加载卡顿 | 图片使用 WebP 格式压缩，预加载 |
| 预设链接失效 | 用户点击无效链接 | 预设链接均为知名网站，低风险 |
| 扩展审核失败 | 无法发布 | MVP 为个人使用，通过开发者模式加载 |
