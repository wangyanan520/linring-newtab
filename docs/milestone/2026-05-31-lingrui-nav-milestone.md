# 凌睿科技导航页 — 里程碑文档 (MILESTONE)

## 1. 里程碑总览

```
M1 ──→ M2 ──→ M3 ──→ M4 ──→ M5 ──→ M6
基础    核心    设置    完善    增强    进阶
骨架    功能    管理    优化    迭代    功能
```

## 2. 里程碑详细定义

### M1：项目基础骨架（预计 1 天）

**目标**：项目初始化，完成扩展基础架构和页面布局

| 任务 | 产出物 | 验收标准 |
|------|--------|---------|
| 项目初始化 | 目录结构、扩展图标 | 目录结构清晰，图标文件就绪 |
| manifest.json 配置 | Chrome 扩展清单 | 安装后新标签页被替换 |
| index.html 骨架 | 导航页 DOM 结构 | 页面可渲染，模块划分完整 |
| styles/main.css | 全局样式+布局 | 居中布局，响应式框架可用 |
| scripts/storage.js | 数据存储层 | 预设数据可读写，CRUD 接口就绪 |

**检查点**：
- [ ] 打开新标签页显示导航页（空白内容）
- [ ] 页面布局居中，背景正常
- [ ] 存储层可正常读写数据

---

### M2：核心功能开发（预计 1.5 天）

**目标**：实现搜索、书签、分类、时间、壁纸核心功能

| 任务 | 产出物 | 验收标准 |
|------|--------|---------|
| 搜索框功能 | 搜索输入+回车跳转 | 输入关键词回车跳转 Google 搜索结果 |
| 快捷书签渲染 | 书签网格展示 | 8 个预设书签显示，点击可跳转 |
| 分类导航渲染 | 分类卡片展示+展开折叠 | 4 个分类显示，点击展开/折叠 |
| 时间显示 | 日期时间实时更新 | 显示年月日星期+时分秒 |
| 壁纸切换 | 壁纸切换功能 | 底部按钮可切换壁纸，刷新后保留 |

**检查点**：
- [ ] 搜索框回车跳转 Google
- [ ] 8 个预设书签显示正常，可跳转
- [ ] 4 个预设分类显示正常，可展开折叠
- [ ] 时间实时更新
- [ ] 壁纸可切换

---

### M3：设置面板开发（预计 1.5 天）

**目标**：实现完整的设置管理面板

| 任务 | 产出物 | 验收标准 |
|------|--------|---------|
| 设置面板 UI | 模态弹窗+Tab 切换 | 点击⚙️弹出，ESC 关闭 |
| 书签管理 Tab | 书签增删改界面 | 可添加/编辑/删除快捷书签 |
| 分类管理 Tab | 分类及链接增删改界面 | 可添加/编辑/删除分类和链接 |
| 设置持久化 | 保存并刷新主页面 | 修改后刷新页面保持最新数据 |
| 设置面板样式 | styles/settings.css | 美观的弹窗样式，适配深浅色 |

**检查点**：
- [ ] 设置面板可正常打开/关闭
- [ ] 可添加书签（名称+网址）
- [ ] 可编辑/删除书签
- [ ] 可添加/编辑/删除分类
- [ ] 分类内可添加/编辑/删除链接
- [ ] 所有修改刷新后保留

---

### M4：完善优化与发布（预计 1 天）

**目标**：体验优化、Bug 修复、发布 MVP 版本

| 任务 | 产出物 | 验收标准 |
|------|--------|---------|
| 细节优化 | 过渡动画、空状态、错误处理 | 操作反馈流畅，无报错 |
| 边缘情况处理 | 存储满、链接无效、图标缺失 | 图标加载失败显示首字母兜底 |
| 响应式适配 | 不同分辨率测试 | 768px~1920px 显示正常 |
| 性能优化 | 加载速度优化 | 页面加载 < 1s |
| 打包发布 | chrome-extension.zip | 可加载到 Chrome 使用 |

**检查点**：
- [ ] 无控制台报错
- [ ] 不同分辨率下布局正常
- [ ] 扩展可正常加载使用
- [ ] 所有 MVP 功能完整可用

## 4. 里程碑门禁标准

每个里程碑完成时必须满足以下门禁条件才能进入下一个里程碑：

### M1 → M2 门禁
- 页面可渲染，无白屏
- 存储层单元测试通过
- Chrome 扩展可正常加载

### M2 → M3 门禁
- 搜索功能正常
- 书签和分类可渲染显示
- 时间实时更新
- 壁纸可切换

### M3 → M4 门禁
- 设置面板所有 CRUD 操作正常
- 修改持久化验证通过
- 数据修改后主页面对应刷新

### M4 → V1.0.0 发布门禁
- 所有 MVP 功能验收清单通过
- 无 P0/P1 级别 Bug
- 页面加载 < 1s
- 扩展包体积 < 5MB

### V1.0.0 → V1.1.0 门禁
- MVP 版本稳定运行
- 主要 Bug 已修复
- 天气 API 可用

### V1.1.0 → V1.2.0 门禁
- V1.1 版本稳定运行
- 无严重 Bug
