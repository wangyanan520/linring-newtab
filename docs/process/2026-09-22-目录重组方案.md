# 目录重组方案（2026-09-22）

## 背景

原结构的三个问题叠加，让根目录难以扫读：

1. 扩展源码目录叫 `凌睿科技导航页/`（中文），与 `docs/`、`scripts/`、`dist/`（英文）并列，
   而它恰恰是全项目最重要的目录；
2. **两个 `scripts/` 同名不同物**：根 `scripts/` 是构建工具（打包 / 体检 / 生成坐标），
   `凌睿科技导航页/scripts/` 是扩展运行时 JS，每次引用都要先判断是哪一个；
3. `docs/` 下混放三类内容：产品文档链（`01`~`10`）、审查与评估报告、协作过程记录。

## 重组前后对照

| 重组前 | 重组后 | 性质 |
|---|---|---|
| `凌睿科技导航页/` | `src/` | 扩展本体，Chrome 直接加载此目录 |
| `凌睿科技导航页/scripts/__tests__/*.test.js` | `tests/unit/` | 单元测试（6 个） |
| `凌睿科技导航页/scripts/__tests__/e2e/nav-e2e.js` | `tests/e2e/nav-e2e.js` | E2E 四模式脚本 |
| `scripts/pack.js`、`ux-audit.js`、`gen-city-coords.js` | `tools/` | 构建期与检查脚本 |
| `docs/product/review-report.md`、`review-report-adversarial.md` | `docs/reviews/` | 审查报告 |
| `docs/项目评估报告.md` | `docs/reviews/` | 独立评估报告 |
| `docs/product/task-allocation.md` | `docs/process/` | 协作过程记录 |
| `docs/product/assets/` | 原地保留 | 产品文档链配图，与引用它的方案同目录 |

全部移动使用 `git mv`，git 识别为改名（`R`）而非删除 + 新增，历史可追溯。

> **给自动化检查的提示**：上表左列是**重组前**路径，重组后已不存在，属预期而非失效引用。
> 任何"文档引用的路径是否存在"的脚本检查，都应按右列判定；本表左列应加入白名单。

重组后根目录条目为 13 项，与重组前持平（少了一个 `scripts/` 与中文源码目录，多了 `tests/`、
`tools/`）。**本次重组减少的是歧义而非条目数量**：两个同名 `scripts/` 的混淆消失，中文与
英文命名不再混杂，源码 `src` / 测试 `tests` / 工具 `tools` / 文档 `docs` 四者边界清晰。

## 引用点更新

| 位置 | 处数 | 内容 |
|---|---|---|
| `package.json` | 6 | npm scripts 中的测试与打包路径 |
| `tools/pack.js`、`ux-audit.js`、`gen-city-coords.js` | 3 | `SRC` / `EXT_PATH` / `CITIES_PATH` 常量 |

| `tests/e2e/nav-e2e.js` | 2 | `EXT_PATH` 上溯层级、`network-audit` 引用 |
| `AGENTS.md`、`CHANGELOG.md`、`.agents/`、`docs/**` | 30+ | 路径引用与目录结构说明 |

`src/index.html` 与 `src/manifest.json` 内部的资源引用是相对路径（如 `scripts/main.js`），
改的是外层目录名，因此**这两个文件一行未动**。

## 验证证据

| 断言 | 结果 |
|---|---|
| 单元测试 `npm test` | 67 / 67 通过 |
| E2E 预览模式 `npm run test:e2e:preview` | 128 / 128 通过 |
| E2E chrome.storage 模式 `npm run test:e2e:shim` | 131 / 131 通过 |
| **分发包 SHA-256** | **`c5e91dd28f9306f85f9993b5e70c0073c87290b245a2612898884fa3c801db92`，与重组前逐字节相同** |

最后一条是本次重组最强的回归断言：只要有任何一个入包文件漏掉或多出，SHA 必然变化。
保持不变即证明目录重组对扩展本体零影响——搬的只是仓库外壳。

## 取舍记录

- **历史报告（`docs/reviews/`）的路径引用同步更新**：不更新会留下失效引用，读者点不开；
  更新的只是路径文本，各报告的结论、数据与证据链未作任何改动。
- **`CHANGELOG.md` 不新增版本节**：分发包字节未变，对使用者不构成"对外变更"。
  本次重组的记录即本文件。
- **未引入 `apps/` 多应用结构**：当前只有一个扩展，按 YAGNI 排除。
- **未固定 Node 版本（`.nvmrc`）**：打包 SHA 受 zlib 版本影响（见 `tools/pack.js` 顶部注释），
  CI 用 Node 20、本机可能不同。是否固定工具链留待需要对外公示构建指纹时再决定。
