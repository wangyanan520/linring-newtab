# 凌睿科技导航页 V2 设计文档

## 1. 概述

凌睿科技导航页 V2 是一次全面的 UI/UX 升级，以"科技感玻璃风"为设计语言，在保留原有核心功能的基础上增加天气和待办事项组件，并引入壁纸自适应取色系统。

### 设计原则

- **精致玻璃质感**: 毛玻璃 + 光影 + 微妙发光边框
- **内容优先**: 保持居中纵向布局，信息层级清晰
- **动态适配**: 界面色彩随壁纸自适应变化
- **渐进增强**: 在现有架构上平滑升级，不破坏已有功能

## 3. 组件设计

### 3.1 背景系统

保持现有的 `bg-layer` + `bg-glow` 双层背景架构。

- **壁纸渲染层**: `#bgLayer` — 使用 CSS `radial-gradient` 生成动态渐变背景
- **光晕层**: `#bgGlow` — 顶部中心光晕，增强立体感
- **自适应取色**: 切换壁纸时，从壁纸 CSS 中提取主色调，应用到界面元素的 accent-color、边框光晕、hover 状态

### 3.2 顶部栏

| 元素 | 说明 |
|------|------|
| 时间 | 左侧显示，格式: `2026年5月31日 星期日 14:30` |
| 天气 | 右侧显示，格式: `☀️ 26°C \| 深圳 · 晴` |

**天气数据获取**: 使用免费天气 API（如 wttr.in 或 和风天气免费版），获取当前城市天气。
- 首次加载时根据 IP 定位城市
- 缓存天气数据 30 分钟
- 显示: 天气图标 + 温度 + 城市 + 天气描述

### 3.3 标题

保持现有样式不变：
- `h1.site-title`: 44px，font-weight 200，渐变文字
- `p.site-subtitle`: 13px，副标题

### 3.4 搜索框（升级）

| 属性 | 当前 V1 | V2 升级 |
|------|---------|---------|
| 圆角 | `--radius-xl` (24px) | 保持 24px |
| 背景 | `rgba(255,255,255,0.05)` | `rgba(255,255,255,0.06)` |
| 模糊 | blur(20px) | blur(24px) |
| 边框 | 1px solid `rgba(255,255,255,0.06)` | 1px solid `rgba(255,255,255,0.08)` + 微弱内发光 |
| 阴影 | 聚焦时 `0 8px 32px` | 增加 `0 0 0 1px` 内边框发光 |

交互行为不变：回车搜索、引擎切换、清除按钮。

### 3.5 快捷书签（升级）

| 属性 | 当前 V1 | V2 升级 |
|------|---------|---------|
| 图标容器圆角 | 16px (`--radius-lg`) | 保持 16px |
| 图标容器背景 | `rgba(255,255,255,0.06)` | 增加 `box-shadow: 0 4px 16px` 微阴影 |
| 悬停效果 | 上移 3px | 增加发光边框效果 |

Favicon 加载逻辑不变。

### 3.6 分类导航（升级）

| 属性 | 当前 V1 | V2 升级 |
|------|---------|---------|
| 卡片背景 | `rgba(255,255,255,0.03)` | 保持不变 |
| 圆角 | 12px | 保持不变 |
| 悬停效果 | 背景略微变亮 | 增加微妙边框发光 |

分类卡片保持在 2 列网格布局。V2 将分类导航放在左侧，右侧新增待办事项面板。

### 3.7 待办事项（新增）

位于分类导航右侧，独立的玻璃卡片。

**数据存储**: 使用 `chrome.storage.local`，新增 `todos` 数据项。

**数据结构**:
```javascript
{
  id: "todo_xxx",
  text: "完成任务文档",
  done: false,
  createdAt: 1700000000000
}
```

**功能**:
- 添加待办（输入框 + 按钮）
- 勾选/取消完成
- 删除待办
- 显示待办数量

**UI**:
- 紧凑型玻璃卡片，宽 200px
- 标题 "✅ 待办事项" + "+" 添加按钮
- 列表项: checkbox + 文字
- 完成的项文字变淡并加删除线

### 3.8 底部工具栏

保持不变，原有的"壁纸"和"设置"按钮。

## 4. 壁纸自适应取色

### 实现方案

在 `WALLPAPERS` 数组中为每个壁纸预设一套颜色变量：

```javascript
{
  name: '深邃星空',
  css: '...',
  colors: {
    accent: 'rgba(150, 100, 255, 0.8)',    // 主色调
    accentLight: 'rgba(180, 160, 255, 0.4)', // 浅色
    glow: 'rgba(150, 100, 255, 0.15)',       // 发光色
    borderGlow: 'rgba(150, 100, 255, 0.12)'  // 边框发光
  }
}
```

切换壁纸时，通过 CSS 自定义属性（`--accent-color`, `--accent-glow` 等）动态更新界面元素颜色。

**影响元素**:
- 搜索框聚焦边框光晕
- 复选框 accent-color
- 分类卡片 hover 边框发光
- 链接 hover 颜色
- 滚动条颜色

## 5. API 变更

### Storage 新增

```javascript
// 新增数据项
Storage.getTodos()        // 获取所有待办
Storage.addTodo(text)     // 添加待办
Storage.toggleTodo(id)    // 切换完成状态
Storage.deleteTodo(id)    // 删除待办
```

### Wallpaper 扩展

```javascript
// 原有方法不变，新增
Wallpaper.getColors(index)    // 获取指定壁纸的颜色配置
Wallpaper.applyColors(colors) // 应用颜色到 CSS 变量
```

## 8. 天气 API

使用 [wttr.in](https://wttr.in) 免费 API（无需 API Key）：

```
https://wttr.in/{city}?format=j1&lang=zh
```

或使用 `https://wttr.in/?format=j1&lang=zh` 自动 IP 定位。

响应解析：
```javascript
{
  current_condition: [{
    temp_C: "26",
    weatherDesc: [{ value: "晴" }],
    weatherCode: "113"
  }],
  nearest_area: [{ areaName: [{ value: "深圳" }] }]
}
```

天气代码映射到 Emoji 图标。

## 9. 响应式设计

| 断点 | 调整 |
|------|------|
| > 768px | 完整布局：分类(左) + 待办(右) 双栏 |
| ≤ 768px | 待办事项移动到分类导航下方，所有卡片单列 |

## 10. 性能考虑

- 天气数据缓存 30 分钟，避免频繁请求
- 壁纸颜色预设跟随壁纸数据，无需运行时计算
- 待办数据使用 `chrome.storage.local` 异步读写
- 所有新增 CSS 使用 `will-change` 和 `transform` 优化动画性能
