# 凌睿科技导航页 — PRD（产品需求文档）

## 1. 产品概述

### 1.1 产品定位
一款 Chrome 浏览器扩展，替换浏览器默认新标签页为"凌睿科技导航页"，为用户提供美观、高效、个性化的上网导航入口。

### 1.2 产品目标
- 替换 Chrome 新标签页为自定义导航页面
- 提供便捷的搜索入口
- 提供常用网站快捷访问
- 提供分类导航组织
- 提供天气、时间等实用信息
- 支持壁纸和主题个性化

### 1.3 目标用户
个人使用，后续可扩展分享给其他用户。

## 2. 功能需求

### 2.1 核心功能

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|-------|
| **新标签页覆盖** | 安装扩展后，Chrome 打开新标签页自动跳转至导航页 | P0 |
| **搜索框** | 集成多搜索引擎（Google/百度/Bing），输入关键词回车搜索 | P0 |
| **快捷书签** | 展示常用网站图标+名称，点击直达，支持增加/编辑/删除 | P0 |
| **分类导航** | 按分类组织网站链接，支持增加/编辑/删除分类及链接 | P1 |
| **天气显示** | 显示当前城市天气、温度 | P1 |
| **时间显示** | 显示当前日期和时间 | P0 |
| **壁纸切换** | 支持多张内置壁纸切换 | P1 |
| **深色模式** | 支持浅色/深色主题切换 | P2 |

### 2.2 功能详情

#### 2.2.1 新标签页覆盖
- 使用 Chrome Manifest V3 的 `chrome_url_overrides` 的 `newtab` 能力
- 安装后即刻生效，无需手动配置

#### 2.2.2 搜索框
- 页面居中醒目位置展示搜索框
- 支持切换搜索引擎（Google / 百度 / Bing）
- 输入关键词后回车，跳转至对应搜索引擎的搜索结果页
- 搜索框有清除按钮和搜索图标

#### 2.2.3 快捷书签
- 展示 8-10 个常用网站图标和名称
- 预设 8 个常用网站（百度、知乎、GitHub、B站、豆瓣、微博、淘宝、抖音）
- 支持添加、编辑、删除快捷书签
- 支持拖动排序
- 图标优先使用网站 favicon，兜底使用首字母

#### 2.2.4 分类导航
- 预设 4 个分类：工具导航、新闻资讯、社交社区、影音娱乐
- 每个分类含 4-6 个链接
- 支持展开/折叠分类
- 支持添加、编辑、删除分类和链接
- 支持分类排序

#### 2.2.5 天气显示
- 页面右上角显示当前天气（城市、温度、天气图标）
- 通过免费天气 API 获取数据（如 OpenWeatherMap 或和风天气）
- 默认根据 IP 自动定位城市

#### 2.2.6 时间显示
- 显示当前日期（年月日+星期）
- 显示当前时间（时:分，秒可选）

#### 2.2.7 壁纸切换
- 内置 6-8 张精选壁纸
- 支持图片模式 / 纯色模式 / 渐变色模式
- 底部工具栏提供切换按钮
- 壁纸设置持久化保存

#### 2.2.8 深色模式
- 支持浅色/深色/跟随系统三种模式
- 深色模式下调整文字颜色和背景透明度

### 2.3 设置面板
- 通过右下角⚙️按钮打开设置面板
- 设置面板支持管理：快捷书签、分类导航、搜索引擎、壁纸、主题
- 设置面板采用模态弹窗形式，不跳转页面

## 3. 非功能需求

### 3.1 性能要求
- 导航页加载时间 < 1s
- 扩展包体积 < 5MB
- 无外部请求阻塞页面渲染

### 3.2 兼容性
- 支持 Chrome 88+ 版本
- 支持 Manifest V3

### 3.3 安全性
- 所有数据存储在浏览器本地，不上传服务器
- 最小权限原则，只申请必要的 API 权限
- 不收集用户隐私数据
